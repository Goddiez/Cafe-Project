# Mysa Cafe — Cafe Project Website

A responsive, multi-page student website prototype built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — home / launch landing page
- `menu.html` — filterable menu + demo shopping bag
- `about.html` — cafe story and values
- `contact.html` — opening hours, fictional location, validated contact form

## Features
- Responsive mobile navigation
- Menu category filtering
- Working demo cart stored in browser `localStorage`
- Add/remove items and calculated total
- Demo checkout confirmation (no real payment)
- Contact form validation and success state
- Accessible labels, semantic sections and responsive layouts
- Original visual identity based on the supplied palette

## Colour palette
- Cream `#FFEAD3`
- Light blue `#BFE7EA`
- Orange `#E89B5B`
- Terracotta `#D46743`
- Supporting dark ink `#17313A`

## Run it
Open `index.html` in a browser. For best results, run a local server from this folder, e.g. `python3 -m http.server 8000`, then open `http://localhost:8000`.
